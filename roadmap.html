Mimari Kararlar

Ağ: Netcode for GameObjects — 5–6 kişi max, Unity Relay entegrasyonu kolay.
Karakter Fizik: CharacterController — Rigidbody değil. Öngörülebilir FPS hareketi.
Input: Direkt Keyboard.current / Mouse.current API (generated class gerektirmez).
Chunk Sistemi: Object Pooling — Instantiate/Destroy yok. Chunk reset = loot ve layout yeniden üretimi.
Proximity VC: Paket seçimi faz 5'te yapılacak (Vivox vs Dissonance vs Photon Voice).
